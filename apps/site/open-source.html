FFmpeg

The installer includes unmodified FFmpeg and FFprobe programs built by gyan.dev, licensed under the GNU General Public License version 3. YT Clipper runs them as separate programs and does not link to them. Their license text and a pointer to the corresponding source code are included in the app's resources/ffmpeg folder, and the source is available from gyan.dev.

Full license texts

Each component's license text ships inside the installed app alongside the component. To request a copy, use the contact options at hasbiyallahu.xyz.
