## Environment gotchas (this machine)

- A local TLS-inspecting CA: Node needs `NODE_OPTIONS=--use-system-ca` for npm/network (`npm install`, Electron download);
  curl needs `--ssl-no-revoke` (schannel revocation check fails); some CDNs (Wikimedia) are extremely slow regardless.
- ffmpeg drawtext on Windows: the drive-colon must be quoted AND escaped (`fontfile='C\:/...'`) or the filtergraph
  parser splits the option; prefer forward slashes.
- ffmpeg spawned from the Electron-backed Python (M5, solved 2026-09-20): with stdin inherited from Electron it can
  finish its whole encode in ~2s and then hang forever at exit (it polls the never-EOF stdin pipe) - fixed with
  `-nostdin` + `stdin=DEVNULL`. A stderr PIPE also made it exit 1 mid-teardown in bisect runs, so stderr goes to a
  temp file; a 180s no-progress watchdog (`render.py` STALL_SECS) kills any wedge as a backstop.
- npm 11 blocks install scripts; `apps/desktop/package.json` `allowScripts` approves electron + esbuild. If
  `node_modules/electron/dist` is missing: `node node_modules/electron/install.js` (retry; downloads are flaky).
- VS Code terminals set `ELECTRON_RUN_AS_NODE=1`, which makes Electron run as plain Node (`app` is undefined).
  `npm run dev|start|smoke` strip it (`scripts/electron-vite.mjs`).


## Background dome clips (2026-11-08)
Twelve short Pexels clips ship inside the renderer (`apps/desktop/src/assets/dome/`, ~2.5 MB) as seamless animated
WebP loops for the app background; ids, pages and authors in `CREDITS.json`. Pexels license: free use, no attribution
required, not resold as standalone stock (they are decoration inside the app). Rebuild with
`apps/desktop/scripts/make-dome-clips.py` (backend venv, reads PEXELS_API_KEY from .env, ffmpeg libwebp_anim).
Animated WebP over GIF: same autoplay-and-loop behaviour as an image, several times smaller.

### Landing site motion (apps/site, 2026-11-08)
- `gsap` 3.13 (GSAP "no charge" standard license, free for commercial use since Webflow's 2024 change; core +
  ScrollTrigger only) drives the pinned "cut" scene, the stacking tour and the scroll-scrubbed word fill.
- `lenis` 1.3 (MIT) gives the smooth scroll; its velocity feeds the hero line and the endless rows.
- The hero (`src/hero.ts`, three.js) reads the app's dome clips (copied to `apps/site/src/assets/footage/`, same
  Pexels licence and `CREDITS.json`) frame by frame with WebCodecs `ImageDecoder` into one atlas texture; browsers
  without it fall back to copying hidden `<img>` frames. The site is light only (owner pick 2026-11-08).
- `npm install` on this machine needs `NODE_OPTIONS=--use-system-ca`, like Wrangler.
